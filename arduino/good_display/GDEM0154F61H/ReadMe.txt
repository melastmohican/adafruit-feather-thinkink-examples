Good Display GDEM0154F61H sample for Adafruit Feather RP2040 ThinkInk
Seated in the onboard 24-pin FPC connector

Pinout (ThinkInk 24-pin connector):
  RST  -> PIN_EPD_RESET (GPIO17)
  CS   -> PIN_EPD_CS    (GPIO19)
  BUSY -> PIN_EPD_BUSY  (GPIO16, active LOW on SSD2681)
  DC   -> PIN_EPD_DC    (GPIO18)
  SCK  -> PIN_EPD_SCK   (GPIO22, SPI1)
  MOSI -> PIN_EPD_MOSI  (GPIO23, SPI1)

Panel: GDEM0154F61H (1.54" 4-color Black/White/Yellow/Red, 200x200, SSD2681)
